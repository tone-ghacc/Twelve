# 固定鍵盤区間

schemaVersion 1 に省略可能な `fixedKeyboardSections` を追加。省略時は従来どおり。

```json
{
  "fixedKeyboardSections": [
    { "id": "keyboard-1", "startMs": 10000, "endMs": 18000, "widths": [3, 2, 2, 2, 3] }
  ]
}
```

- 時間範囲は開始を含み終了を含まない。譜面内の整数ms、開始 < 終了。区間同士の重複は不可、隣接は可。
- `widths` は1〜6個の正整数、合計12。配列から境界を累積計算する。分割数は表示のプリセットであり、判定に分割数別の分岐はない。
- **分割は見た目のみ。入力は従来の12レーン・隣接1レーン許容を維持する。**
- 制作画面の「固定鍵盤区間」で追加・変更・削除でき、タイムラインにも境界を表示する。JSONの読み込み・保存・ダウンロードは既存処理を利用。

## ランダム

プレイ設定で開始前に有効化する。表示予定のノーツが途中で飛ばないよう、プレイ準備時に各区間の `originalLane -> randomizedLane` 置換を一度確定し、そのプレイ中は維持する。やり直しでは再生成。一時停止では維持。分割配列自体は変更しない。

ノーツJSONを複製してレーンを変換してから、既存の判定イベントを生成する。描画と判定が同じ変換済みデータを見る。編集元JSONには置換を保存しない。区間外のノーツは元のレーンに置く。

幅のあるノーツが分裂しないよう、全てのノーツ幅・終点フリック幅が連続する12要素の全単射に制限する。包含関係も保たれるので連結を維持できる。区間境界をまたぐホールド・連結チェーンは、そのチェーン全体と使用レーンの対応を固定する。終点が区間終了と同時刻の場合も固定する。譜面の制約によっては入れ替えが小さい、または恒等置換になる。探索回数には上限を設け、未解決なら恒等置換に戻る。

## 表示と寿命

`Game.fixedKeyboard` の `active` は現在の区間、`effects` は開始済みの光演出を保持する。開始時に1回だけ光を登録し、終了時は `active` を解除するが、`effects` は独立に0.85秒の寿命を終えるまで残す。続けて別区間が始まった場合は複数の光を同時に扱う。一時停止では演出も停止し、譜面終了直前の光はリザルト中も完走する。

遠近計算の `progress` / `laneX` / `laneScale` を流用し、画面手前の外側から最奥の外側へ光を走らせる。通過済みの部分だけを塗り分け、分割線を形成する。区間終了後は分割線と塗り分けを即座に消し、光だけを残す。ノーツ速度・判定時刻には影響しない。
